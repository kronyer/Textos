### 2.1 We consider $(\mathbb{R} - \{-1\},\star)$ where
$$a\star b = a + b + ab$$

a. Show that $(\mathbb{R} - \{-1\},\star)$ is an abelian group.

Um grupo abeliano é um conjunto $G$ com uma operação binária $\cdot$ que satisfaz as seguintes propriedades:
1. Fechamento: Para todo $a, b \in G$, $a \cdot b \in G$.
2. Associatividade: Para todo $a, b, c \in G$, $(a \cdot b) \cdot c = a \cdot (b \cdot c)$.
3. Elemento neutro: Existe um elemento $e \in G$ tal que para todo $a \in G$, $e \cdot a = a \cdot e = a$.
4. Elemento inverso: Para cada $a \in G$, existe um elemento $a^{-1} \in G$ tal que $a \cdot a^{-1} = a^{-1} \cdot a = e$.
5. Comutatividade: Para todo $a, b \in G$, $a \cdot b = b \cdot a$.

Para mostrar que $(\mathbb{R} - \{-1\},\star)$ é um grupo abeliano, precisamos verificar cada uma dessas propriedades.

1. Fechamento: Para $a, b \in \mathbb{R} - \{-1\}$, temos
$$a \star b = a + b + ab$$
Como $a$ e $b$ são números reais diferentes de $-1$, a expressão $a + b + ab$ também é um número real diferente de $-1$. Portanto, $a \star b \in \mathbb{R} - \{-1\}$, o que mostra que a operação é fechada. (pq?)

2. Associatividade: Para $a, b, c \in \mathbb{R} - \{-1\}$, temos

Tomemos quaisquer $a, b, c \in \mathbb{R} - \{-1\}$.

Calculamos $(a \star b) \star c$:
$(a + b + ab) \star c = (a + b + ab) + c + (a + b + ab)c$

Calculamos $a \star (b \star c)$:
$a \star (b + c + bc) = a + (b + c + bc) + a(b + c + bc)$   
Agora, vamos expandir ambos os lados:
$(a + b + ab) \star c = a + b + ab + c + ac + bc + abc$
$a \star (b \star c) = a + b + c + bc + ab + ac + abc$
Comparando os dois resultados, vemos que ambos são iguais:
$a + b + ab + c + ac + bc + abc = a + b + c + bc + ab + ac + abc$

Portanto, $(a \star b) \star    c = a \star (b \star c)$, o que mostra que a operação é associativa.

$\square$

3. Elemento neutro: Precisamos encontrar um elemento $e \in \mathbb{R} - \{-1\}$ tal que para todo $a \in \mathbb{R} - \{-1\}$, $e \star a = a \star e = a$.

Vamos tentar encontrar esse elemento neutro. Suponha que $e$ seja o elemento neutro. Então, para todo $a \in \mathbb{R} - \{-1\}$, temos:
$e \star a = e + a + ea = a$
Rearranjando a equação, obtemos:
$e + ea = 0$
$e(1 + a) = 0$
Como $a \neq -1$, temos $1 + a \neq 0$. Portanto, a única maneira de satisfazer essa equação é se $e = 0$.

Agora, vamos verificar se $0$ é realmente o elemento neutro:
$0 \star a = 0 + a + 0 \cdot a = a$
$a \star 0 = a + 0 + a \cdot 0 = a$

Portanto, o elemento neutro é $0$.


4. Elemento inverso: Para cada $a \in \mathbb{R} - \{-1\}$, precisamos encontrar um elemento $a^{-1} \in \mathbb{R} - \{-1\}$ tal que $a \star a^{-1} = a^{-1} \star a = 0$.

Vamos tentar encontrar o elemento inverso para um elemento $a \in \mathbb{R} - \{-1\}$. Suponha que $a^{-1}$ seja o elemento inverso de $a$. Então, temos:
$a \star a^{-1} = a + a^{-1} + aa^{-1} = 0$
Rearranjando a equação, obtemos:
$a^{-1} + aa^{-1} = -a$
$a^{-1}(1 + a) = -a$
$a^{-1} = \frac{-a}{1 + a}$

Agora, precisamos verificar se $a^{-1} \in \mathbb{R} - \{-1\}$. Para isso, precisamos garantir que $1 + a \neq 0$, o que é verdade porque $a \neq -1$. Portanto, $a^{-1}$ é um número real diferente de $-1$.

5. Comutatividade: Para $a, b \in \mathbb{R} - \{-1\}$, temos
$a \star b = a + b + ab$
$b \star a = b + a + ba$
Comparando as duas expressões, vemos que $a \star b = b \star a$, o que mostra que a operação é comutativa. 

Portanto, $(\mathbb{R} - \{-1\},\star)$ é um grupo abeliano.

$\square$

b. Solve: $3 \star x \star x = 15$

Vamos resolver a equação $3 \star x \star x = 15$.

Podemos começar calculando $3 \star x$:
$3 \star x = 3 + x + 3x = 3 + 4x$
Agora, precisamos calcular $(3 \star x) \star x$:
$(3 + 4x) \star x = (3 + 4x) + x + (3 + 4x)x = 3 + 4x + x + 3x + 4x^2 = 3 + 8x + 4x^2$
Agora, podemos substituir isso na equação original:
$3 + 8x + 4x^2 = 15$
Rearranjando a equação, obtemos:
$4x^2 + 8x + 3 - 15 = 0$
$4x^2 + 8x - 12 = 0$
Dividindo toda a equação por 4, temos:
$x^2 + 2x - 3 = 0$
Agora, podemos fatorar a equação quadrática:
* Soma dos coeficientes: $2$
* Produto dos coeficientes: $-3$
Os números que satisfazem essas condições são $3$ e $-1$. Portanto, a fatoração da equação é:
$(x + 3)(x - 1) = 0$

Isso nos dá as soluções:
$x + 3 = 0 \implies x = -3$
$x - 1 = 0 \implies x = 1$
