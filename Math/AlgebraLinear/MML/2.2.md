2.2: Let $n$ be in $\mathbb{N}$. Let $k,x$ be in $\mathbb{Z}$. We define congruence class $\overline{k}$ of the integer $k$ as the set:
$$ \overline{k} = \{x \in \mathbb{Z} : x - k = 0 (\text{mod } n)\} $$
$$= \{x \in \mathbb{Z} : \exists a \in \mathbb{Z}, x - k = na\}$$

We now define $\mathbb{Z}/n\mathbb{Z}$ (sometimes written $\mathbb{Z}_n$) as the set of all congruence classes modulo $n$. Euclidian division imples that this set is a finite set containing $n$ elements:
$$\mathbb{Z}/n\mathbb{Z} = \{\overline{0}, \overline{1}, \ldots, \overline{n-1}\}$$

For all $\overline{a}, \overline{b} \in \mathbb{Z_n}$m we define
$$\overline{a} \oplus \overline{b} = \overline{a + b}$$

## Pensando intuitivamente esse conjunto
Para materializar esse $\mathbb{Z_n}$. Suponha $n=3$

Um conjunto $\overline{k}$, portanto, é o conjunto de infinitos numeros que se comportam como k, quando divididos por 3.

Por exemplo, $\overline{0} = \{0, 3, -3, 6, -6, \ldots\}$, $\overline{1} = \{1, 4, -2, 7, -5, \ldots\}$ e $\overline{2} = \{2, 5, -1, 8, -4, \ldots\}$.

Ou seja, são os numeros que, divididos por 3, deixam o mesmo resto. O conjunto $\mathbb{Z_3}$ é o conjunto de todos os conjuntos $\overline{k}$, ou seja, $\mathbb{Z_3} = \{\overline{0}, \overline{1}, \overline{2}\}$.

## Resolvendo
a. Show that ($\mathbb{Z}/n\mathbb{Z}, \oplus$) is an abelian group.

Mais uma vez, para provarmos que $(\mathbb{Z}/n\mathbb{Z}, \oplus)$ é um grupo abeliano, precisamos verificar as propriedades de fechamento, associatividade, elemento neutro, elemento inverso e comutatividade.

1. Fechamento: Para $\overline{a}, \overline{b} \in \mathbb{Z}/n\mathbb{Z}$, temos
$$\overline{a} \oplus \overline{b} = \overline{a + b}$$
Como $a$ e $b$ são inteiros, a soma $a + b$ também é um inteiro. Portanto, $\overline{a + b}$ é um elemento de $\mathbb{Z}/n\mathbb{Z}$, o que mostra que a operação é fechada.

2. Associatividade: Para $\overline{a}, \overline{b}, \overline{c} \in \mathbb{Z}/n\mathbb{Z}$, temos
$$(\overline{a} \oplus \overline{b}) \oplus \overline{c} = \overline{a + b} \oplus \overline{c} = \overline{(a + b) + c}$$

E sendo $a, b, c$ inteiros, temos sua associatividade, ou seja, $(a + b) + c = a + (b + c)$. Portanto,
$$(\overline{a} \oplus \overline{b}) \oplus \overline{c} = \overline{a + (b + c)} = \overline{a} \oplus (\overline{b} \oplus \overline{c})$$
O que mostra que a operação é associativa.

3. Elemento neutro: Precisamos encontrar um elemento $e \in \mathbb{Z}/n\mathbb{Z}$ tal que para todo $\overline{a} \in \mathbb{Z}/n\mathbb{Z}$, $e \oplus \overline{a} = \overline{a} \oplus e = \overline{a}$.

Começamos com uma suspeita do $\overline{0}$ ser o elemento neutro. Vamos verificar isso:
$$\overline{0} \oplus \overline{a} = \overline{0 + a} = \overline{a}$$
$$\overline{a} \oplus \overline{0} = \overline{a + 0} = \overline{a}$$
Portanto, o elemento neutro é $\overline{0}$.

4. Elemento inverso: Para cada $\overline{a} \in \mathbb{Z}/n\mathbb{Z}$, precisamos encontrar um elemento $\overline{a^{-1}} \in \mathbb{Z}/n\mathbb{Z}$ tal que $\overline{a} \oplus \overline{a^{-1}} = \overline{a^{-1}} \oplus \overline{a} = \overline{0}$.

Pensando logicamente, se andamos $a$ passo em um circulo de tamanho $n$, quanto falta para voltarmos para o ponto de partida? A resposta é $n - a$. 

Vamos verificar isso:
$$\overline{a} \oplus \overline{n - a} = \overline{a + (n - a)} = \overline{n}$$


E como $n$ é um múltiplo de $n$, temos $\overline{n} = \overline{0}$. Portanto, o elemento inverso de $\overline{a}$ é $\overline{n - a}$.

5. Comutatividade: Para $\overline{a}, \overline{b} \in \mathbb{Z}/n\mathbb{Z}$, temos
$$\overline{a} \oplus \overline{b} = \overline{a + b}$$
$$\overline{b} \oplus \overline{a} = \overline{b + a}$$
Como a adição de inteiros é comutativa, temos $a + b = b + a$. Portanto,
$$\overline{a} \oplus \overline{b} = \overline{b} \oplus \overline{a}$$
O que mostra que a operação é comutativa.


Portanto, $(\mathbb{Z}/n\mathbb{Z}, \oplus)$ é um grupo abeliano.
