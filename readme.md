## Como usar
- Cada arquivo tem seu próprio checklist — abra só o que for estudar hoje.
- Itens riscados (`~~texto~~`) = decidiu não estudar / não vale a pena, mantidos só como histórico.
- Quando um assunto ficar 100%, mova o arquivo pra uma pasta `concluidos/` ou apague a linha daqui do índice.
- Os links acima usam sintaxe `[[pasta/arquivo.md|Nome]]` — funcionam direto no Obsidian; no VSCode puro, use `Ctrl+Click` no caminho relativo ou instale a extensão **Markdown Link Preview** / **Foam** pra eles virarem clicáveis.
